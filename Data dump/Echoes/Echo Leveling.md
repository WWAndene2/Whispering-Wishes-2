Source: reference page "Echo/Leveling" page. Extracted from user-provided .mht 2026-09-06. The page's own Refunding section is intentionally excluded per request.

## Sources of Echo EXP

Two sources: Echo Development Materials (Sealed Tubes), and feeding an already-Upgraded Echo into another (grants 75% of that Echo's own EXP; the used Echo is removed from inventory).

| Material | EXP Provided |
|---|---|
| Basic Sealed Tube | 500 |
| Medium Sealed Tube | 1,000 |
| Advanced Sealed Tube | 2,000 |
| Premium Sealed Tube | 5,000 |

## Shell Credit Cost

- Each Echo EXP point requires **0.1 Shell Credit**.
- Each Tune attempt requires **2,000 Shell Credit**.
