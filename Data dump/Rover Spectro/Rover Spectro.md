## Review

- DPS Tier (as Support): T1.5 (Tower of Adversity), T2 (Whimpering Wastes). Value Tier: T1.5 / T3.
- **Pros**: high personal damage while retaining good healing; mandatory with one of the best DPS
  characters in the game (Spectro Frazzle synergy); fills Forte fast for quick rotations; flexible
  Echo-set teambuilding; character + all Sequences free (rare enemy-RES-shred access); fast/precise
  attack frames make parrying easier; Outro slows enemies for comfort.
- **Cons**: high survivability but buffs less than other characters in the same niche; unconventional,
  non-straightforward rotations requiring swap-in/out timing; only really wanted in one team (Spectro
  Frazzle niche), risking replacement in the future.
- Free 5★ Spectro Hybrid Sword, jack-of-all-trades: healing, CC, debuff, DoT, Sub-DPS. Kit revolves
  around Spectro Frazzle (DoT, ticks every 3s based on stacks/enemy DEF/RES/level, caps at 10 stacks) —
  currently only Spectro Rover and Phoebe apply/exploit it.
- Applies Frazzle via Liberation (6 stacks flat) and enhanced Resonance Skill (2 stacks); 2 Skills + 1
  Ultimate caps it at 10 stacks. Skill's 6s cooldown lets full-stack application happen fast on
  multiple targets thanks to Ultimate's good AoE.
- Forte (Diminutive Sound, cap 100, consumes 50 per enhanced Skill cast) fills via Basic Attack, Intro,
  or (most efficiently) Heavy Attack → Aftertune follow-up.
- Enhanced Skill Resonating Spin: 2 Frazzle stacks, enhanced damage, extra whirling attack (Resonating
  Whirl), applies Shimmer (stops Frazzle decay for 9s), enables up to 2 Resonating Echoes follow-ups.
  S6 gives Spin/Slashes hits -10% Spectro RES on the target for 20s (non-stacking).
- All Sequences are free: S1 15% Crit Rate on Skill cast, S2 20% Spectro DMG, S3 20% Energy Regen, S4
  team heal (20% ATK/s for 5s on Ultimate), S5 40% Liberation DMG, S6 10% Spectro RES shred.
- Gameplay/role varies by Echo set: Rejuvenating Glow → fills the healer role itself (any heal, however
  small, triggers Rejuvenating Glow's team ATK buff) — skip building Outro, focus purely on Frazzle
  application, shortest field time; typically paired with a Moonlit Clouds Hybrid or quickswap 2nd DPS.
  Moonlit Clouds → the ATK buff instead comes from Outro, so Outro must be built up (longer rotation),
  typically paired with a traditional healer for high-survivability teams.
- Meta position: awkward jack-of-all-trades — only true niche is being the Frazzle applier mandatory
  for Phoebe (who out-applies Frazzle herself via her Hybrid mode once another Frazzle-DPS exists, so
  Rover's relevance depends on Phoebe's continued need for a co-applier). Together, the pair form one
  of the strongest teams in the game regardless of any future outclassing risk.

Frazzle appliers focused purely on damage using this set specifically.

## Gameplay and Teams

**Rotation** (Burst Combo — role is fast Concerto generation + efficient Frazzle application/
maintenance + well-timed Echo use): time the Echo right before the team's highest-damage combo. Heavy
ATK → Resonance → Aftertune → Forte: Resonating Spin → Forte: Resonating Whirl → (swap out while
waiting on Skill CD) → Intro → Ultimate → Basic P1 → P2 → Forte: Resonating Spin → Forte: Resonating
Whirl → Forte: Resonating Echoes P1 → P2 → Outro.

**Synergies**: Phoebe (Absolution Phoebe needs a Frazzle applier — S6's RES Shred adds more damage;
Ultimate's healing lets Rover run either Rejuvenating Glow or Moonlit Clouds to fit Phoebe's other
teammates; also a fantastic Support for Phoebe-Zani/Confession Phoebe). Zani (great Support alongside
Phoebe via RES Shred/Frazzle/personal damage/Rejuvenating Glow triggers; usable as a Phoebe substitute
but lacks her Frazzle DMG Amp and full-combo Frazzle exploitation — still perfectly viable for endgame
clears). Ciaccona (great Frazzle-team partner — matches Confession Phoebe's application speed together;
Ciaccona's off-field Frazzle application gives an edge in multi-wave content). Verina (generalist healer
— run on Rejuvenating Glow paired with a Moonlit Clouds Rover; easy, fast rotation, team-wide ATK% +
15% DMG Amp). The Shorekeeper (premium healer alternative — 12.5% Crit Rate, 25% Crit DMG, 25% ATK, 15%
DMG Amp to the team; same Rejuvenating Glow + Moonlit Clouds Rover pairing).

**Example Teams**: Best Team / Premium Phoebe Teams (Ciaccona is Absolution Phoebe's best/only real
partner in Whimpering Wastes, best with Shorekeeper there specifically), F2P Phoebe Team, Quickswap
Phoebe Team (only for players experienced with quickswapping), Phoebe Triple Spectro Team (run Rover on
Moonlit Clouds here) — exact roster icons weren't machine-readable in this extraction; team names/
conditions themselves are directly from the source text.

**2026-09-09 full kit audit** (independent re-derivation, zero deference to the pass above — this
time the TriggerBlocks engine was NOT already correct for S1/S6 despite the prior pass's claim; found
4 real bugs):

4. **S1 incorrect always-on passive**: `roverspectro.chain.s1`'s Crit Rate +15% was modeled as an
   unconditional `trigger:{type:'passive'}` with no duration, but her own kit text is explicit this is
   a real cast-scoped window ("Casting Resonating Slashes or Resonating Spin -> Crit Rate +15% for
   7s"). Confirmed via direct measurement: with the old model, enabling S1 raised the Heavy ATK warm-up
   combo's own hit damage — but that combo is the FIRST step in the modeled rotation, firing BEFORE
   either Resonating Slashes or Resonating Spin has ever been cast. Fixed to a real 7s window anchored

   since the base Skill is never used — see item 5).
5. **S6 anchored to a move that never fires**: `roverspectro.chain.s6`'s Spectro RES Shred -10% was
   anchored to `'Skill:Resonating Slashes'` — the block's own prior note already admitted this move
   never appears in `CHARACTER_ROTATIONS['Rover: Spectro']` (the warm-up step is Heavy ATK, and Forte
   auto-upgrades Skill straight to Resonating Spin), making this a confirmed no-op: direct measurement
   showed sequence-5 and sequence-6 totals were byte-identical. S6's own kit text explicitly names BOTH
   "Resonating Slashes/Resonating Spin hit" as valid triggers, so re-anchored to `Forte:Resonating
   Whirl` (the real Resonating Spin cast that fires twice in the modeled rotation) — now a real, active
   debuff for any S6 dupe owner running this rotation.
6. **Comment/code mismatch — missing `damage.category`**: `roverspectro.intro.waveshock`'s header

   never set — the same exact bug found on Rover: Aero's and Rover: Havoc's own Intro blocks earlier

7. **`dmgFocus` mislabeled-share bug**: the prior 2026-09-03 pass's own comment on `dmgFocus` claimed
